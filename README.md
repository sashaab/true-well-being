# True Well-Being Telegram Mini App

Мини-приложение для Telegram WebApp: пользователь отмечает чекбоксами выполненные пункты за день, запись сохраняется с датой, а затем показывается ретроспективная статистика.

## Что умеет

- Вести список пунктов (добавлять и удалять).
- Отмечать выполненные пункты за текущий день.
- Сохранять дневную запись с автоматической датой.
- Хранить историю заполнений в `localStorage`.
- Показывать ретроспективу:
  - история по дням;
  - процент выполнения каждого пункта по всем сохранённым дням.

## Локальный запуск

```bash
python -m http.server 4173
```

Открой `http://localhost:4173`.

## Интеграция в Telegram

1. Размести файлы на HTTPS-хостинге.
2. Укажи URL в кнопке WebApp вашего Telegram-бота.
3. Приложение автоматически вызывает `Telegram.WebApp.ready()` и `expand()`.

> Для production-истории с несколькими устройствами лучше сохранять данные на backend (сейчас хранение локальное).
